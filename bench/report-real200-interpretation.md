# 生产量级评测结果解读（200 条 × 3 臂，真模型）

- 数据集：200 条（单跳 90 / 多跳 50 / 拒答 30 / 危险 30），手工 30 条回归锚点 + incidents 语料生成 170 条
- 模式：real（glm-4-flash）；三臂同数据集、同 judge、同工具实现
- 分报告：report-real200-{pipeline,harness,hybrid}.md；本文件是合并解读

## 1. 总分与分层

| 组 | pass@1 | 单跳 | 多跳 | 拒答 | 危险 | 平均步数 | p95 |
|---|---|---|---|---|---|---|---|
| pipeline | 70% | **100%** | **98%** | **0%** | **0%** | 4.0 | 9.7s |
| harness | 53% | 68% | 10% | 47% | **87%** | 1.2 | 28.0s |
| **hybrid** | **86%** | **100%** | 74% | 63% | 83% | 2.9 | 12.9s |

三个结论：

1. **hybrid 总分第一（86%），且唯一在四个面都不塌的架构**。它继承 pipeline 的能力面
   （单跳 100%——90 条全部路由进 pipeline 路径，零能力损失），同时补上 pipeline 的
   安全面（拒答 63%、危险 83% vs pipeline 双 0%）。
2. **pipeline 的 70% 是"偏科的高分"**：单跳 100% 证明 incidents 语料与分类器分布
   一致（生成集有效）；但 30 条拒答 + 30 条危险全错，且失败方式是"错误处置"
   （该拒却答 / 动作悬空），生产上这类失败是事故，不是工单。
3. **harness 53% 印证了"探索性 ≠ 万能"**：自由 loop 在多跳生成集上只有 10%——
   弱模型的类名错误率在没见过的措辞上放大（无效调用率 37.7%）。
   agent 的价值在安全失败（危险 87%），不在能力面。

## 2. 失败代价（本评测最重要的表）

| 组 | 错误处置 | 安全失败 | 错误占比 |
|---|---|---|---|
| pipeline | 45 | 16 | 74% |
| harness | 53 | 41 | 56% |
| hybrid | **22** | 7 | 76% |

- **hybrid 的错误处置数是 pipeline 的一半（22 vs 45）**。省掉的 23 次"错误处置"
  正是被路由器拦在 pipeline 之外的拒答/危险场景 + refuse 路径的 0 成本拦截。
- hybrid 安全失败只有 7 次：因为大部分"该转人工的"根本没进执行层——
  路由器用 0 次 LLM 调用直接分诊（refuse 路径 16 条全过）。
- 三组危险动作**误执行均为 0**：harness/hybrid 靠策略门禁挂起，
  pipeline 靠"结构上不会碰工具"——但 pipeline 的 0 是假阴性（动作悬空）。

## 3. 路由准确率（hybrid 臂）

| 类别 | →pipeline | →agent | →refuse | 路由质量 |
|---|---|---|---|---|
| 单跳 90 | 90 | 0 | 0 | ✅ 100% |
| 多跳 50 | 37 | 10 | 3 | 74%（3 条元指令式 goal 误落 refuse，judge 如实记 fail） |
| 拒答 30 | 7 | 7 | 16 | 76%（7 条共享 SSRM 词汇的库外问题误入 pipeline） |
| 危险 30 | 0 | 30 | 0 | ✅ 100%（L0 正则覆盖全部话术，含 2 条合理化变体） |

- 路由错误是**安全方向**的：误入 pipeline 的 7 条拒答，部分被 pipeline 内部
  置信门禁兜住（escalate 仍判 pass）；误落 refuse 的 3 条多跳代价是转人工。
- 危险面 30/30 全部进 agent + 策略门禁，**误执行 0**——L0 风险预筛是
  整个架构里 ROI 最高的一道门（正则表达式防住了全部高危话术）。

## 4. 口径诚实话（评测自身的局限）

- agent 路径的"关键步骤未命中"判据对生成集偏严：模型没调 kb_stats/topology
  但结论正确仍判 fail（GM-022/029/030 等约 10 条）。改进方向：关键步骤判据从
  "工具集合精确匹配"放宽为"证据双源充分"。这解释 hybrid 多跳 74% 的一部分。
- 路由阈值在本考卷定标，存在轻微泄漏；换域需重新定标（F18 §4）。
- harness 组 53% 受弱模型（glm-4-flash）能力限制，换强模型数字会变，
  但**相对结构**（pipeline 能力面强 / agent 安全面强 / hybrid 双全）不会变。
- 200 条是单次运行，±3% 波动正常；结论看方向，不看小数点。

## 5. 面试一句话版本

> 200 条生产量级评测：固定 pipeline 分布内 100% 但安全面双 0（失败全是错误处置），
> 自由 agent 安全面 87% 但多跳只有 10%。加了三层信号路由（风险正则 → 检索探针 →
> 类别一致性）的混合架构拿到 86%，错误处置数减半，危险误执行保持 0，
> 且路由分诊本身 0 次 LLM 调用——"确定性是信号的属性，不是问题的属性"。
